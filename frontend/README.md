# ElectroHub Frontend

This is the frontend for the ElectroHub application, built with React and Vite.

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables in `.env`:
   ```env
   VITE_API_URL=http://localhost:5000
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Key Technologies
- **React**: UI library
- **Vite**: Build tool
- **TailwindCSS**: Styling
- **Axios**: API requests
- **Lucide React**: Icons
